# GANZA Barbearia — Site Premium

Site oficial em **um único arquivo** (`index.html`), 100% autocontido:

- ✂️ Intro com navalha que abre revelando o nome da barbearia
- 🏠 Hero com foto real da barbearia (gradiente premium) e logo
- 🎠 Tarja "rolling" com efeitos de scroll
- 📅 Formulário de agendamento com validação + confirmação
- 📱 100% responsivo (mobile first ajustes)
- 🖼️ Logo e foto de fundo **embutidas em base64** — nada de imagens externas quebrando
- 🚫 Zero dependências externas (funciona offline)

## Deploy no Vercel

Este é um site estático — o Vercel detecta automaticamente, **sem build**:

1. Acesse [vercel.com/new](https://vercel.com/new)
2. Importe este repositório
3. Framework Preset: **Other** (deixe em branco -- Build Command e Output Directory vazios)
4. Clique em **Deploy**

Pronto! O site sobe com o `index.html` na raiz servido como página principal.
